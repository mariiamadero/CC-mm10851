For my interaction, I wanted to include both the face and hands. Telling gestures apart was the first thing I struggled with + a bit of mirroring. At first I tried checking every finger, but it wasn't reliable, so I made a function called fingerIsUp that compares how far a fingertip is from the wrist to how far the middle joint of that finger is from the wrist. A straight finger reaches farther than a curled one, so it works even when my hand is tilted. I only check the index and middle fingers.

The video was originally flipped but the hand data wasn't so my finger moved the wrong way until I flipped its position with width - x. I mirror the video with push(), translate(width, 0), scale(-1, 1) and pop(), and the width - x makes the finger position line up with what I see on screen.

Picking from the menu was also tricky since I realized it would essentially pick instantly. I made a timer variable dwellTimer which would count how many frames my finger stayed on the same box and it would restart at 0 if I moved to a different one. Once it passed 40 frames, the choice continues and the timer resets so it doesn't instantly pick again on the next menu.

For the wave effect, I had to draw the video in thin strips and slide each strip sideways with sin() and then make the waves grow while I drink and slowly fade out after. Each strip is 4 pixels tall and moves by sin(y * 0.05 + frameCount * 0.1) * waveAmount, so every strip gets a different offset and frameCount makes it move. waveAmount goes up a little each frame while I drink (capped at 40 with min()) and gets multiplied by 0.99 every frame so it fades.

The glass emptying took some work too. It only counts as drinking when the distance between my hand and faceMesh point 13 (the middle of the lips) is under 120 pixels. A variable called level starts at 100 and goes down by 0.5 each frame while I drink, and the liquid height is 60 * (level / 100), anchored to the bottom of the glass so it looks like it drains from the top. When level hits 0 it goes back to the first menu.
